Guitar Tab Editor — Instructions

This is the browser version of the stage-readable guitar tablature editor. It runs entirely as a static web app: no account or server database is required to edit tabs.

Recommended browser

Use a current desktop version of Google Chrome or Microsoft Edge. The editor also works in other modern browsers, but the native Save Clean JSON As… location picker is best supported in Chromium-based browsers.

Basic workflow

  1. Prepare a clean tab JSON with the agreed transcription workflow.
  2. Open the editor and click Load Clean Tab JSON.
  3. Optionally click Load Draft Reference to keep the handwritten draft visible beside the clean tab.
  4. Review and correct fret numbers, strings, chords, section names, and barlines.
  5. Use Save Clean JSON As… to save the approved clean version.
  6. Use Transpose only after the clean version is approved.
  7. Use Print / PDF for the A4 stage-readable output.

Editing fret numbers

  • Click an existing fret number to select it and hear it when Sound is enabled.
  • Ctrl-click on Windows/Linux or Command-click on macOS to select multiple fret numbers.
  • Type a value in Fret and use Apply to selected.
  • Use String ↑ and String ↓ to move selected notes between strings.
  • Use Delete to remove selected fret numbers.
  • Click an empty position on a string to add a fret using the current Fret value.

Sections, chords, and bars

  • Double-click a section label to rename it.
  • Double-click a chord to edit it.
  • Right-click a chord to delete it.
  • Double-click above a staff to add a chord.
  • Click Add barline, then click the desired horizontal position in a staff.

Stage layout

The editor uses the locked A4 layout designed for reading from an approximately 11-inch tablet: large tab systems, bold condensed text, large fret numbers, section labels close to their tab boxes, and TAB letters inside the box between strings 2–3, 3–4, and 4–5.

Transcription rule used with this editor

The clean transcription workflow treats the string physically touched by a handwritten number as the primary string assignment. Horizontal placement follows the handwritten draft. Chord shapes are used as validation. Every sounded note must belong to the major scale of the written song key; muted x marks are exempt.

Your files and privacy

JSON files and draft images that you open are read locally by the browser. This app has no backend upload function and makes no network request to store your tab content. Saving produces a file on your own device.

Updating the online editor

To publish a newer version later, replace index.html in the GitHub repository and commit the change. GitHub Pages will redeploy the updated site automatically from the configured publishing branch.
